# Perceptron - An Idle Game

Un jeu incrémental inspiré de Perceptron, basé sur les réseaux de neurones.

## 🎮 Jouer en ligne avec GitHub Pages

Pour rendre ce jeu accessible via une URL web :

1. **Va sur GitHub** : https://github.com/philippepatou/claudetest

2. **Accède aux Settings** :
   - Clique sur "Settings" (icône d'engrenage en haut à droite du repo)

3. **Active GitHub Pages** :
   - Dans le menu de gauche, clique sur "Pages"
   - Sous "Branch", sélectionne `claude/perceptron-idle-game-011CUh1UZxVeTcohvuTnCQQK`
   - Garde le dossier sur `/ (root)`
   - Clique sur "Save"

4. **Accède au jeu** :
   - Après 1-2 minutes, ton jeu sera disponible à l'adresse :
   - **https://philippepatou.github.io/claudetest/**

## 💻 Jouer localement

1. Télécharge les fichiers : `index.html`, `style.css`, `game.js`
2. Mets-les dans le même dossier
3. Double-clique sur `index.html`

## ✨ Fonctionnalités du jeu

- **Training Data** : Ressource principale du jeu
- **Nodes** : Génèrent des données automatiquement
- **Layers** : Débloquent de nouvelles fonctionnalités
- **Computing Power** : Booste la vitesse de production (+10% par ordinateur)
- **Shop** : Achète des améliorations permanentes
- **Prestige (Ensembles)** : Reset avec bonus de production permanents (+15% par ensemble)
- **Sauvegarde automatique** : Ton progrès est sauvegardé toutes les 30 secondes
- **Progression offline** : Le jeu continue de progresser même quand tu ne joues pas

## 🎯 Comment jouer

1. Clique sur "Train Network" pour générer de la data manuellement
2. Achète des nodes pour générer de la data automatiquement
3. Débloque des layers pour accéder au shop et aux ordinateurs
4. Achète des upgrades pour améliorer ta production
5. Crée des ensembles (prestige) pour des bonus permanents

Amuse-toi bien !
