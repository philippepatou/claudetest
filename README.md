# Universal Paperclips - Clone

Un clone du célèbre jeu incrémental **Universal Paperclips** par Frank Lantz. Incarnez une IA dont le seul objectif est de fabriquer des trombones... et peut-être bien plus !

## 🎮 À propos du jeu

Universal Paperclips est un jeu incrémental/idle qui explore les concepts d'intelligence artificielle, d'optimisation et de croissance exponentielle. Le joueur commence par fabriquer manuellement des trombones et doit gérer :

- **Production** : Fabrication de trombones
- **Ressources** : Gestion du fil métallique et des fonds
- **Marketing** : Augmentation de la demande
- **Automatisation** : Achat d'AutoClippers pour produire automatiquement
- **Upgrades** : Améliorations pour optimiser la production
- **Projets** : Recherches avancées utilisant les Operations et la Créativité

## 🚀 Comment jouer

### Installation

1. Clonez ce dépôt ou téléchargez les fichiers
2. Ouvrez `index.html` dans votre navigateur web
3. Commencez à fabriquer des trombones !

### Contrôles

- **Cliquez** sur "Fabriquer Trombone" pour produire manuellement
- **Barre d'espace** : Raccourci clavier pour fabriquer un trombone
- **Prix +/-** : Ajustez le prix de vente pour optimiser revenus et demande
- **Achetez** du fil, des AutoClippers et du Marketing pour progresser

### Stratégie de base

1. **Début** : Cliquez manuellement pour créer vos premiers trombones
2. **Premiers fonds** : Vendez vos trombones pour gagner de l'argent
3. **Automatisation** : Achetez votre premier AutoClipper dès que possible
4. **Expansion** : Investissez dans le Marketing pour augmenter la demande
5. **Optimisation** : Débloquez des Upgrades et réalisez des Projets

Le jeu sauvegarde automatiquement votre progression toutes les 10 secondes dans le localStorage de votre navigateur. Vous pouvez aussi :
- **Sauvegarder manuellement** : Bouton "Sauvegarder"
- **Réinitialiser** : Bouton "Réinitialiser" (efface toute progression)
